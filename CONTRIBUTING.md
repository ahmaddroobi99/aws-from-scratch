# Contributing to aws-from-scratch

This repository is an educational lab. Keep changes small and explain the concept they teach.

## Principles

1. Simple first. Two services, one database, one frontend.
2. Explain everything. If you add a tool, document why it exists.
3. Show the abstraction. What is AWS hiding?
4. Local first. It must work on a laptop before it works on AWS.
5. Failure is part of the lesson.

Use conventional commits: feat, docs, fix, test, chore.
